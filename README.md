# AI Resume Analyzer

## About
AI Resume Analyzer is a web application that analyzes resumes using AI and helps users understand their resume content.

## Features
- Upload a resume in PDF format
- Analyze resume content using Google Gemini AI
- Display analysis results through a web interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Google Gemini API

## Live Demo
https://ai-resume-analyzer-4l64.onrender.com/

## Installation

1. Clone this repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Create a `.env` file and add your Gemini API key using the environment variable name expected by `app.py`.
4. Run the application:

   `python app.py`

## Deployment
The application is deployed using Render.

## Note
A valid Gemini API key and available API quota are required for AI analysis.
